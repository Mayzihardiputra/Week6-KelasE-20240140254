# Week 6 - Fetch API & Form DOM / Event Handling

Tugas individu PAW Week 6.

## Fitur
1. **Fetch API** - mengambil produk dari `https://dummyjson.com/products`, menampilkan nama, harga, gambar, dan kategori; ada status loading, error + tombol muat ulang, dan pencarian.
2. **Form Pendaftaran Workshop** - validasi real-time (`input`, `blur`, `change`), penghitung karakter, `submit` dengan `preventDefault`, hasil tampil dinamis, dan `reset`.

## Struktur
```
index.html
css/style.css
js/produk.js   # Fetch API
js/form.js     # Form DOM & Event Handling
```

## Cara menjalankan
Buka `index.html` di browser (butuh koneksi internet untuk Fetch API).
